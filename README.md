# Exam-and-PAN-Card-Resizer-Tool
A 100% client-side, privacy-focused Exam and PAN Card Image/PDF Resizer. Features pre-configured specs for SSC, RRB, and PAN portals with auto KB-targeting, DPI injection, B&amp;W conversion, and instant PDF compression. Built with HTML, Tailwind CSS, jsPDF, and PDF.js.
